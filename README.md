# Maktkart

Hvem bestemmer i kommunen din? Maktkart viser organene, rollene og pengene, og
hvordan de henger sammen. Hver påstand har kilde og dato. Tromsø er først ute.

- Produkt og krav: [`docs/spec/2026-09-24-maktkart-mvp.md`](docs/spec/2026-09-24-maktkart-mvp.md)
- Designsystem: [`DESIGN.md`](DESIGN.md)
- Arbeidsregler og invarianter: [`CLAUDE.md`](CLAUDE.md)

```bash
npm install
npm run dev
npm test
```
